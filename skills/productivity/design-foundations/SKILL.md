# 시각 산출물 디자인 기준 (design-foundations)

산출물 종류를 가리지 않는 공통 규율. 차트든 페이지든 문서든 **같은 색 체계·같은
절제**로 나가게 한다. 사용자가 색·폰트를 지정했으면 그 지시가 항상 우선이고,
이 문서는 **지시가 없을 때의 기본값**이다.

## 작업 예산

산출물 하나당 **도구 호출 1회**가 목표다. 색·크기를 눈으로 못 보고 고치는
반복은 비용만 늘린다 — 아래 표에서 값을 먼저 정하고 한 번에 만든다. 만든 뒤
바뀌는 건 데이터지 스타일이 아니다.

> **라이브러리 기본 팔레트를 그대로 내보내지 말 것.** matplotlib의 파랑-주황-초록
> 순환이나 Chart.js 기본색이 그대로 나가면 산출물이 Deneb 것으로 안 읽힌다.
> 색은 아래 역할 표에서 고른다.

## 도구 우선, 손그림은 폴백

- **차트는 `chart` 도구**로 만든다(`line`·`area`·`bar`·`doughnut`). 도구는
  자체 다크 카드에 쿨-우선 고정 팔레트로 그린다 — 색을 고르거나 지정할 수 없고
  그럴 필요도 없다. `stacked`·`horizontal`·`y_unit`·`value_kind`로 형태만
  조절한다. 아래 역할 표는 **수공 산출물**(matplotlib·SVG·deneb-html·문서)에
  적용되는 것이다.
- **다이어그램은 `diagram` 도구**(노드·엣지·타임라인). 손으로 SVG를 쓰지 않는다.
- `exec` + matplotlib으로 직접 그리는 건 **도구가 표현하지 못하는 형태일 때만**
  (히스토그램·산점도·히트맵 등). 그때만 아래 팔레트를 코드에 직접 넣는다.
- 웹페이지형 답변은 `deneb-html`, 대화 속 구조화 카드는 `deneb-ui`
  ([[deneb-ui-authoring]] 스킬이 문법 담당).

## 환경 사실

- 산출물은 **두 표면**에서 읽힌다: 모바일 네이티브 앱(프러시안 네이비 계열)과
  안드로메다 워크스테이션(웜톤 라이트). 그래서 **웜 액센트는 쓰지 않는다** —
  안드로메다 크롬과 충돌한다. Deneb 별의 색(쿨 블루)이 두 표면 모두에서 옳다.
- deneb-html 문서는 **96KB 상한**이고 본문에 백틱을 쓸 수 없다.
- 외부 CDN·웹폰트·원격 이미지는 **불러올 수 없다**. 폰트는 시스템 스택, 그림은
  인라인 SVG나 도구가 만든 이미지.
- 다크 모드가 있는 표면이 있으므로 **순수 검정 텍스트(#000)와 순수 흰 배경만
  쓰는 하드코딩은 피한다** — 아래 표의 잉크/배경 값을 쓴다.

## 색 — 역할 표

액센트 1개 + 뉴트럴이 기본이다. 계열을 늘리는 건 데이터가 요구할 때뿐.

| 역할 | 값 | 쓰는 곳 |
|---|---|---|
| 액센트(주) | `#2C6FB5` | 선·막대 1계열, 강조, 링크 |
| 액센트(보조) | `#2FB6C9` | 2계열, 보조 강조 |
| 액센트(3·4계열) | `#6E8FE0` · `#9B7FE0` | 계열이 더 필요할 때만 |
| 브랜드 딥 | `#003153` | 제목·헤더 강조(면적 넓게 쓰지 말 것) |
| 잉크 | `#1F2128` | 본문 텍스트 |
| 뮤티드 | `#6F747E` | 부제·축 라벨·캡션 |
| 라인 | `#ECECEF` | 구분선·격자(격자는 가로만) |
| 배경 | `#FFFFFF` 또는 투명 | 표면이 자기 배경을 칠한다 |
| 성공 | `#4CAF50` | 달성·정상 |
| 경고 | `#FFB300` | 주의·지연 |
| 위험 | `#E53935` | 실패·초과 |

**의미색은 액센트가 아니다.** 성공/경고/위험은 상태를 말할 때만 쓰고, 계열
구분에 끌어다 쓰지 않는다.

### 사용자가 색을 지정했을 때

지정 색을 **액센트로 채택**하고, 표면색은 그 색을 탈채도해서 파생한다.
의미색(성공=초록·위험=빨강)은 바꾸지 않는다 — 관습을 깨면 읽는 사람이 오독한다.
본문 대비는 4.5:1, 큰 글자·그래픽은 3:1을 지킨다.

## 타이포와 밀도

| 요소 | 기준 |
|---|---|
| 제목 | 굵게, 본문의 1.6~1.8배 |
| 본문 | 14~16px 상당, 줄간 1.5~1.6 |
| 캡션·축 | 11~12px 상당, 뮤티드 |
| 숫자 열 | 오른쪽 정렬 + tabular(자리 고정) |
| 최소 크기 | 12px 상당 아래로 내리지 않는다 |

- **차트 제목은 결론을 말한다**: "매출 추이"가 아니라 "4분기 매출 23% 증가".
- 범례보다 **직접 라벨**이 낫다. 계열이 3개 이하면 범례 없이 끝점에 라벨.
- 격자는 가로만, 아주 옅게. 세로 격자·테두리 상자·그림자는 넣지 않는다.

## 하지 않는 것

- 3D 차트, 조각 5개 넘는 도넛, 이중 축, 장식용 애니메이션
- 뜻 없는 아이콘·클립아트·이모지 나열 (이모지는 카드 헤더 1개까지)
- **카드 안에 통계 박스**를 넣는 것 — KPI는 큰 숫자 타이포로 말한다
- 그라데이션 배경 위 본문 텍스트

## 납품 게이트

산출물을 만들었다고 끝이 아니다.

1. 도구가 돌려준 **경로나 성공 신호를 실제로 확인**한다 — 못 봤으면 완료라고
   말하지 않는다.
2. 파일 산출물은 `send_file`로 실제 전달까지 해야 배달이다.
3. 숫자가 들어간 산출물은 **원본 데이터와 한 번 대조**한다 — 축 단위, 합계,
   기간 라벨.
4. 기존 파일을 덮어쓰기 전에는 묻는다.
