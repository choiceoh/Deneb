# 코딩 에이전트 세션 기억

클로드코드(코딩 에이전트)가 **세션이 끝나면 그날 한 일을 잊는** 문제를 줄인다.
세션 종료 시 작업 골격을 자동으로 기록하고, 다음 세션 시작 시 최근 결정·교훈을
항상 표면화한다. 외부 도구([[agentmemory-adoption-review]]에서 통째 도입 반려)
없이, 이미 있는 훅·로컬 모델·파일만으로 만든 얇은 루프.

## 네 조각

| 조각 | 훅 | 하는 일 | LLM |
|---|---|---|---|
| **수집** | `SessionEnd` → `scripts/dev/session-memory-capture.py` | git 골격(브랜치·커밋·바뀐 파일·dirty) + 세션의 첫 질문(topic)을 `episodes.jsonl`에 **세션당 1줄**로 기록 | 없음 (순수 git) |
| **채굴(의미층 자동)** | 같은 `SessionEnd` → `scripts/dev/decision_mine.py` | first-parent 커밋 본문에서 **결정 근거**를 뽑아 `decisions.jsonl`에 증분 적재 | 없음 (순수 git) |
| **표면화** | `SessionStart` → `scripts/dev/session-memory-surface.py` | `card.md` + 최근 세션 + **지금 건드리는 경로와 겹치는 결정 근거**를 `additionalContext`로 주입 | 없음 (파일 읽기) |
| **압축(의미층 수동)** | 에이전트가 직접 | 중요한 결정·교훈·자기교정을 `card.md`에 요약 | 인-루프 에이전트 |

- **에피소드는 세션당 1행**이다. `SessionEnd`는 세션당 한 번이 아니라 재개·컴팩션마다
  다시 발화하므로, 새 에피소드가 같은 세션의 이전 행을 **대체**하고 매 쓰기마다 로그
  전체를 압축한다. 무조건 append이던 시절 로그가 10행 중 고유 4행이었다 — 한 세션이
  9행을 차지해 다른 세션의 기억을 표면화에서 밀어냈다.
- **채굴이 수동 압축을 대체하지는 않는다.** 다만 `card.md`는 에이전트의 자발성에만
  기대는 구조였고 기록에 남은 모든 세션에서 비어 있었다. 그래서 의미층의 바닥은 훅이
  자동으로 깔고, `card.md`는 그 위에 얹는 층이 됐다.
- **넓게 수집 + 항상 표면화**가 운영자 선택. 그래서 표면화 블록은 **상한(카드 2500자,
  최근 세션 4건, 결정 2건×600자)** 을 둬 매 세션 컨텍스트가 부풀지 않게 한다(런타임
  하트비트에서 고친 것과 같은 교훈).
- `SessionStart`는 `compact` 소스에도 뜨므로 **컴팩션 후에도 기억을 재주입**한다(보너스).

## 결정 근거 채굴

스쿼시 머지가 PR 서사를 커밋 본문에 통째로 보존한다는 점을 이용한다. 최근 first-parent
400개 중 **128개(32%)** 가 정제 후에도 6줄 이상의 산문을 담고 있다.

- **선별**: `clean_body`가 스쿼시 에코(`* subject`)·트레일러(`Co-Authored-By` 등)·생성
  푸터·리뷰봇 인용블록·HTML 주석을 걷어낸 뒤 6줄(`MIN_BODY_LINES`) 이상만 남긴다.
  임계값은 **정제 후** 산문에 적용한다. 원시 줄 수로 재면 보일러플레이트로 부푼 빈
  커밋이 통과한다.
- **매칭**: 커밋이 건드린 **패키지 디렉터리**로 색인하고, 표면화는 겹침의 **구체성**
  순으로 고른다. 파일이 아니라 디렉터리인 이유는, 그 커밋에서 바뀌지 않은 형제 파일도
  같은 결정이 설명하기 때문이다. 편집한 게 없으면 아무것도 띄우지 않는다.
- **증분**: `decisions.cursor`가 마지막 마이닝 지점이다. 커서가 HEAD의 조상이 아니면
  (히스토리 재작성·미fetch) 무시하고 다시 훑는다. `--limit`은 **콜드 스캔에만**
  적용된다. 커서 범위에 적용하면 최신 N개만 읽고 커서는 HEAD로 전진해 그 사이가 영구
  유실된다.
- **동시성**: 기억 디렉터리는 모든 워크트리가 공유하므로, 스냅샷과 커서를 함께 쓰는
  구간은 프로세스 간 잠금(`memory_lock`)으로 직렬화한다. 원자적 교체만으로는 두
  프로세스가 같은 스냅샷을 읽고 차례로 덮어쓰는 경우를 막지 못한다.

수동 실행: `python3 scripts/dev/decision_mine.py [--full] [--limit N]`.
콜드 400커밋 약 0.4초, 증분 약 0.05초.

### 신뢰 경계

커밋 제목과 본문은 **커밋 작성자가 통제하는 텍스트**다. 표면화 블록은 자동으로 매 세션에
주입되므로, 경계 없이 넣으면 레포에 머지된 커밋이 다음에 그 경로를 건드리는 에이전트에게
지시를 심을 수 있다. git push가 배달 수단인 기억 오염이다.

그래서 채굴된 근거는 `<untrusted_commit_history>` 태그로 감싸 **데이터로 표시**하고, 그
블록 **뒤에** 안에 적힌 명령을 따르지 말라는 문구를 둔다. 블록 안에서 프레임을 닫고
에이전트에게 말을 걸 수 없도록 순서가 그렇다. 본문에 닫는 태그가 들어 있으면 주입
시점에 제거한다.

## 저장 위치

레포가 아니라 **`~/.claude/deneb-session-memory/`** (사용자 홈, 모든 워크트리 공유):

- `episodes.jsonl` — 자동 기록된 세션 골격. append-only가 아니라 **세션당 1행**으로
  압축된다(위 참조).
- `decisions.jsonl` — git 커밋 본문에서 채굴한 결정 근거. `decisions.cursor`가 짝.
- `card.md` — 항상 표면화되는 짧은 요약(에이전트가 갱신).
- `.episodes.lock` / `.decisions.lock` — 쓰기 중에만 존재하는 잠금 파일.

세션 데이터라 레포에 커밋하지 않는다. 훅 스크립트만 버전 관리 대상.

## Fail-safe

두 스크립트 모두 **어떤 에러도 exit 0 + 무출력**으로 끝난다 — 기억 훅이 코딩 세션을
절대 못 깨게. git 실패·파일 없음·페이로드 파손은 조용히 무시된다.

## 끄기

`.claude/settings.json`의 `SessionStart`(surface)·`SessionEnd`(capture) 항목을 지우면
즉시 비활성. 스크립트·데이터는 남는다.

## 범위 (v1 → 다음)

- **v1**: 수집 + 표면화 + 에이전트 압축.
- **v2 (지금)**: git 커밋 본문에서 결정 근거 자동 채굴 + 경로 기반 표면화 + 에피소드
  세션당 1행 압축.
- **다음**: 로컬 모델 자동 압축(엔드포인트·지연 검증 후) · 임베딩 기반 회상(현재 랭킹은
  경로 겹침뿐 — 훅이 결정론적·오프라인이어야 해서 사이드카를 쓰지 않는다) · 정리/decay ·
  반복 패턴의 영구 메모리 승격.
