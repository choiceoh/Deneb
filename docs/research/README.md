# Research notes — historical snapshots

이 폴더의 문서들은 **작성 시점의 스냅샷**인 내부 리서치/분석 노트다. 내비게이션
(`docs/docs.json`)에 연결된 소수를 제외하면 frontmatter 의무도 면제된다
(`docs/agent-rules/docs.md`).

**여기 서술을 현재 상태로 믿지 마라.** 은퇴한 시스템(Telegram 봇, Hindsight,
Termux/SSH 폰 브리지, vega, Dropbox 연동 등)과 옛 호스트명(gx10→srv1,
spark4tb→srv2), 과거 모델 라인업이 현재형으로 등장할 수 있다 — 의도된 기록이다.
현행 사실의 단일 진실원은 루트 `CLAUDE.md` + `docs/agent-rules/*.md` + 각 모듈
`CLAUDE.md`이고, 드리프트 스윕도 이 폴더는 제외한다.
