# 0001. 분석/비서 페르소나 분리 금지

**Status:** accepted (retrospective)

## Context

Deneb은 NVIDIA DGX Spark 위의 단일 사용자 개인 AI 에이전트다. 초기 설계에서
"업무분석(깊이)"과 "업무비서(능동)"를 별도 페르소나(에이전트)로 나누는 안이
검토될 수 있었으나, 단일 사용자·단일 머신 환경에서는 두 역할이 같은 기억·같은
문맥·같은 목소리를 공유해야 한다.

## Decision

하나의 "비서실장형" 페르소나가 업무분석과 업무비서를 **동시에** 수행한다.
분석/비서 페르소나 분리는 금지한다. 기기별 반응형 레이아웃(모바일/데스크톱
표면 차이)은 허용한다.

## Alternatives rejected

- **분석 페르소나와 비서 페르소나를 별도 에이전트로 분리** — 문맥·기억이
  갈라지고 사용자에게 두 목소리가 노출됨. 단일 사용자에겐 복잡도 대비 이득 없음.

## Consequences

- 한 페르소나가 넓은 책임을 지므로 "좁고 깊게, 옵션보다 opinionated 기본값"이
  운영 원칙이 된다.
- 위키 KB·Polaris 세션 메모리가 단일 페르소나의 연속성 기반이다.
- 문서(CLAUDE.md 등)에 "분석/비서 페르소나 분리 금지"가 명시적 제약으로 남는다.
