# Plaud 회의 전사 용어집 (초기 v1.1 · 위키+주소록 기반 (계열 임원 보강))

> 출처: 위키 인물/업무/프로젝트 대표·회의록 「표기 교정」·사용자 직접 정정(2026-07).
> 운영: 새 회의록에서 반복되는 교정만 여기로 승격. 일회성·"(추정)"만 있는 항목은 넣지 않음.
> 게이트웨이 로드: `topics/plaud-glossary.md` (최대 ~12K자).

## 1. 사용자 확인 교정 (최우선)

- 이마댐 → 임하댐
- 당안리 → 당암리
- 고려대 / 고려대학교 / 고려전기 / 고려단선 → 고려전선
- 일렉 / Electric → 화신일렉트릭
- 디오 / DIO → 디원
- 구자연 / 구재환 / 구자환 → 구자현 (TS스틸 대표)
- 박승수 → 박상수 (화웨이 기술 담당; 총괄은 이지용 부장)

## 2. 고신뢰 교정 (회의록에서 반복)

- 메가 / 메가당 / N 메가 → MW / MW당 (발전용량·단가 맥락)
- 헥사 / 핵사 → Hexa / 헥사리뉴어블
- 썬그로우 → Sungrow
- K-F → K-Fence
- 융복개편서 → 융복합단지
- 개공량 → 개소량
- 기초상금 → 지체상금
- 상토 부장 / 천암두 → 차남두 부장
- 박암리 / 박하민 / 박강정 → 박환민
- 작서리 건 → 당진 솔라빌리지 건 (문맥 맞을 때)
- 보이트 → VOIT
- 스티어 → 케이블 트레이 (문맥: 케이블 포설)
- 수팔레트 → 수상 팔레트
- 회귀라는 답 → 회신이라는 답

## 3. 단위·동음이의 (판단)

- 발전용량·단가: 메가 → MW (예: 12메가→12MW, 광주 82메가→82MW)
- 철골·모듈·자재 개수: 매 → 매(장) 유지. MW로 바꾸지 말 것 (예: 6매→6장)
- 중량 → 톤 / 소형 설비·인버터 → kW
- 2,9m(발전) → 2.9MW — 확신 없으면 유지

### 기획조정실 (실무)
- 1팀: 김승리 차장 / 공명한 차장 / 김성환 대리 / 송동휘 대리
- 2팀: 이영민 차장 / 김대희 과장 / 고건 대리 / 김유영 주임
- 3팀: 김성훈 이사 / 김세미 과장 / 김운 이사
- 토지·인허가: 정현도

### 계열사 대표·주요 임원
- 남도에코에너지: 오선택 (대표) / 박민수 차장 / 이시연 주임 / 제용범 상무
- TS스틸: 구자현 (대표이사) — ASR: 구자연/구재환/구자환 → 구자현
- 바로(주): 김빛날희호 (대표이사) — ASR 깨지기 쉬움, 정규 표기 유지
- 디원: 윤창국 (대표) — ASR: 윤창욱 → 윤창국 (회의 맥락)
- 한국전기이엔지: 김우성 (대표) / 박형도 (대표·대행 맥락)
- 화신일렉트릭 / 화신이엔지 / TS파워텍 / 제주탑솔라 / 시티플러스 / 한국전기기술 / 한국기전 — 대표명 위키 미확정 시 회사명만 정규화
