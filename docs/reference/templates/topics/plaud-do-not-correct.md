# Plaud 교정 금지

> 여기 있는 변환은 **절대 적용하지 않는다**. 잘못된 과교정·동음이의 함정.
> 형식: `A ≠ B` 또는 `A → B` (둘 다 금지로 해석).

## 인물 (혼동 금지)

- 오형석 ≠ 오선택
- 오선택 ≠ 오형석
- 구자현 ≠ 구자연
- 박환민 ≠ 박하민
- 차남두 ≠ 상토

## 단위·동음이의 (과교정만 금지)

> 철골 개수 "매"↔발전용량 "MW"는 문맥 판단(교정 지침). 여기엔 **방향이 항상 틀린** 것만.

- MW → 매
- MW → 톤
- 톤 → MW
