# 응답 중 전송 대기열(#3026) 후속 결함 수정 4종 + 접근성 1종
답변 중 대기열에 넣은 메시지가 대화를 전환하거나 새 채팅을 시작한 뒤 엉뚱한 대화로 자동 전송되던 문제를 고쳤습니다 — 이제 전환 시 자동 전송을 멈추고, 직접 입력한 메시지는 입력창에 되돌려 둡니다.
턴이 게이트웨이 오류로 끝났을 때(⚠️ 말풍선)도 대기 메시지가 곧바로 자동 전송되던 문제를 고쳤습니다 — 실패한 턴 뒤에는 입력창으로 되돌려 사용자가 직접 다시 보냅니다.
입력창에 다음 메시지를 쓰는 중에 턴이 실패하면 대기 중이던 메시지가 조용히 사라지던 문제를 고쳤습니다 — 이제 쓰던 초안 뒤에 이어 붙여 보존합니다.
대기열 메시지가 첨부 파일을 함께 기억해서, 나중에 붙인 첨부가 먼저 나가는 다른 메시지에 흡수되지 않습니다.
"답변 후 전송" 안내의 취소가 더 넓은 터치 영역을 갖고 스크린리더에서 버튼으로 읽힙니다.
